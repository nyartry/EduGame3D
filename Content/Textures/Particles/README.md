# Particle Textures

Place particle sprite textures here, such as smoke, spark, fire, magic, dust, and hit effect images.

Recommended formats:
- PNG for alpha-blended particles.
- JPG only for opaque or mask-free textures.

Suggested naming:
- `smoke_soft.png`
- `spark_star.png`
- `fire_core.png`
- `dust_puff.png`
