# アニメーション再生・ルート変位・イベントの契約

`Framework/Animation/AnimationPlayback` は有限の正のクリップ長と前進更新を受け取り、同じ更新の開始局所秒・終了局所秒・通過した周回数を返します。局所時刻は `double` の `[0, duration)` に保ち、長時間再生で大きな `float` の累積時刻を作りません。ゼロ・逆方向・非有限・周回数で表現できない更新幅は進行しません。不正なクリップ長は静止として扱います。

`AnimationSampler` はこの局所秒を直接サンプルし、独自には周回させません。抽出用に `duration` ちょうどを渡した場合は終端をサンプルします。`RootMotionExtractor` は端点差と全周回分の変位を合計し、モデル倍率を適用します。クリップ長の後にキーがあっても実際のクリップ終端を使います。出力はモデル局所の XYZ です。既存のキャラクター側の水平合成・ジャンプ中のプログラム Y 優先は変えません。

`AnimationEvents` はエディターと実行系で同じ `open-campus-animation-events-v1` の読込・保存処理を使います。schema、必須の時刻/アニメーション名/type、有限かつ非負の時刻、JSON 構文を検証し、無効データは理由付きで失敗します。実行系の文字列に編集バッファの制限はありません。エディターに収まらない文字列は切り捨てず、読込エラーにします。

イベントは更新区間 `(開始, 終了]` に対して発火し、複数周でも全通過分を時系列順に列挙します。同じ境界を次の更新で再発火しません。時刻 0 のイベントは周回時のみ発火し、初期再生・シーク・クリップ変更では発火しません。時刻 `duration` と時刻 0 に別々のイベントを置いた場合は、周回境界で終端イベント、次周の 0 イベントの順に両方発火します。別クリップのイベントとクリップ範囲外の時刻は発火しません。異常に大きい更新で無制限にイベントを確保しないよう、列挙には既定 4096 件の上限があり、超過は `length_error` として通知します。

`SkinnedModel` はモデルと同じ場所の `.anim_events.json` を任意で読み込みます。`AddAnimation(name, path)` で追加したファイルのイベントは追加先の名前へ対応付けます。各シミュレーションの `Update` 後、次の更新までに `ConsumeAnimationEvents()` を呼ぶと、その更新分の意味イベントを一度取得できます。未読イベントは次の `Update`、シーク、クリップ変更で消去します。イベントに応じた音・攻撃・エフェクトなどは取得側で選択し、Framework からバックエンドを直接呼びません。

`tools/test_root_motion.ps1 -Configuration Debug`（または `Release`）で、抽出の一周・複数周・小数長・キーの範囲・無効値、既存ジャンプ Y、イベント境界、schema/JSON 検証、エディターと実行系の日本語パスを含む保存読込の回帰を実行できます。

GameScene は各固定更新直後に `SkinnedMeshActor::ConsumeAnimationEvents()` を消費します。`Footstep` と `PlaySE` は `cue` を既存音サービスの登録IDとして再生し、`PlayEffect` は既存エフェクトサービスへ渡します。`bone` が有効ならボーンのワールド位置、空または未検出ならActor原点を使います。空cueは無視します。`HitboxStart` / `HitboxEnd` / `Custom` のゲーム固有処理はまだ定義していません。既存サンプルの `footstep_default` は音素材として未登録のため、鳴らすにはGameのカタログへIDと素材を登録してください。
