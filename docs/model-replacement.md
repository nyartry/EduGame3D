# EduHumanへのモデル置換記録

実施日: 2026-09-14。対象: EduGame3Dの3Dモデルとキャラクターアニメーション。

所有者の依頼に基づき、外部の無料素材を新規制作の人型モデル **EduHuman** へ置き換えました。形状はプリミティブ、動作は数式とキーフレームからCodexの支援で生成しています。旧モデルの形状・画像・骨格・モーションを加工したものではありません。編集できるBlenderデータと生成スクリプトを同梱します。

## 変更内容

- 操作キャラクターを `HumanoidPlayer` に変更。待機、移動、キックの3FBXを使用します。
- 静止展示を `HumanoidFigure`、歩行サンプルを `HumanoidWalker` に変更。同じ人型を使います。
- 未使用の旧キャラクタークラスも整理しました。
- `Content/Models/Player`、`Daven`、`55-rp_nathan_animated_003_walking_fbx`、`Y_Bot` と付属画像・旧イベントファイルを除外しました。
- 所有者が自作と確認した `Untitled` の2FBXは維持しています。
- キック用イベントファイルとエディターの説明を新モデルに合わせました。

旧素材の実体は復元用にソースツリー外のローカルフォルダーへ退避しています。ゲームやソース出力は参照しません。

操作方法と描画の土台は既存のゲームを使用します。キックはXで1回再生し、0.5〜1.2秒の受付中にもう一度Xを押すと次のキックを予約します。移動中のモデルはその場で走るアニメーションとし、実際の移動はゲームの入力・衝突処理で行います。

モデル一覧・再生成は [モデルREADME](../Content/Models/README.md)、制作経緯は [PROVENANCE](../Content/Models/EduHuman/PROVENANCE.md) を参照してください。

## 検証

実ファイルを読み込む `ModelPreparationTests` に、骨階層と全身のウェイト、3FBX間の骨格互換性、各クリップによる部位の変位、キックの長さとイベント発火を検証する3件を追加しました。さらに実頂点の身長・接地位置と両足の前向きを検証し、FBXの座標変換の抜けを検出します。

2026-09-14に以下を確認しました。

- `tools/validate_core.ps1 -Configurations Debug,Release` 成功。構造・プロジェクト登録、両構成のソリューションビルド、12組のコマンドラインテスト、各構成90件のネイティブテスト、4シェーダーのVS/PSコンパイル。
- 同梱AssimpでIdle/Jog/Kickが各1クリップ、長さが2.4/0.8/1.6秒であること。座標はY-up・正面-Z、全クリップで共通のbind姿勢。素の身長は1.7915、ゲーム内で1.8へ正規化。
- GameAppの本編で操作キャラクター・静止展示・歩行サンプルの3体を表示。
- Animation Event EditorでKickと隣のイベント2件を読み込み、0.723秒のキック姿勢を正面から表示。
- 個人のBlenderスタートアップ設定を初期化して再生成し、保存した制作元を別プロセスで再読込。scene 1 / object 2 / action 3 / material 6 / image 0を確認。

Debugリンク時には既存RmlUiライブラリのPDB未同梱に関する警告が出ますが、ビルドとテストは成功しています。GPU回帰テストは既存のWARP経路を含みます。ゲーム入力の操作感の評価とは区別します。

## Git履歴を含まないソース出力

リポジトリのルートで次を実行します。

```powershell
.\tools\export_clean_source.ps1
```

既定では `x64/CleanSource/EduGame3D/` と `x64/CleanSource/EduGame3D-clean-source.zip` を生成します。別の場所を使う場合は `-OutputDirectory` を指定します。既存出力の更新は、出力先を確認したうえで `-Force` を付けます。スクリプトが作った出力であることを確認できない場所は上書きしません。

出力には現在のファイル内容を使い、`.git`、Git LFSオブジェクト保管庫、ローカルのビルド結果・設定を含めません。`Content/Models` はEduHumanとUntitledおよび説明文書のみを許可します。旧外部FBX8点のSHA-256との一致や未取得のLFSポインターを検出した場合は中止します。依存ライブラリの実体と既存のライセンス文書は保持し、モデルの照合用に `MODEL_MANIFEST.json` を出力します。

この作業は既存リポジトリの履歴を書き換えません。旧素材はPrivateのGit履歴・LFSに残ります。既存リポジトリをそのままPublicへ変更する判断は別途必要です。GitHubの公開設定は変更していません。

## 今回の範囲

外部3Dモデル・モーションへの依存を除いた構成です。音源、エフェクト素材、クレスト画像、外部コードの権利整理は [権利台帳](rights-inventory.md) に残っています。この置換だけでプロジェクト全体の権利確認やSARTRASの分配判断が完了するわけではありません。
