## 利用場面ごとの確認

| 行うこと | EduGame3Dの利用条件・報告の扱い |
|---|---|
| 正規の配布元から入手し、手元で読む・ビルドする・実行する・改変する | [LICENSE第2項](../LICENSE) の範囲で無償利用できます。外部ライブラリ・対象外素材は個別条件を確認してください。 |
| 公開済みのGitHub URLを学生に紹介する | URLを示すだけならSARTRASの利用報告は不要です。教材を別途アップロードしてそのURLを示す場合は別です。 |
| コードの一部や解説を教材へ取り込み、LMS・オンライン講義で送信する | 第35条等の適用を学校の担当者と確認し、学校が行う利用報告の対象なら記載してください。本ライセンスは教材送信の包括的な無償許諾を与えていません。 |
| ソフトウェア一式を学生へ再配布する | コードを読んで学ぶ教材配信と分けて、許諾範囲を確認してください。第35条で一式の配布が認められるとは限りません。 |
| このプロジェクトの保護される部分を含むゲーム・実行物・ソースを公開・配布・販売する | **事前の個別相談と許可が必要です。** 無料の作品公開や就職用ポートフォリオの配布も含みます。法令上の例外とGitHub規約に基づく閲覧・fork等は維持します。 |

URL紹介の区別は [SARTRAS公式手引き8頁](https://sartras.or.jp/wp-content/uploads/guide_to_filing_a_usage_report.pdf#page=8) に基づきます。学生が公開元から直接cloneし、ローカルで使うだけの場合も、学校による教材の再送信と区別する整理です。後者はGit固有の公式回答ではなく、この原則を当てはめたものです。

法令上認められる引用などには、個別の許可を求めません。授業目的であっても、利用範囲や送信先が第35条の要件を満たすかを確認してください。一般向けに公開する授業動画や教材を、受講者限定の授業配信と同じ扱いにしないでください。[第35条運用指針](https://sartras.or.jp/unyoshishin-2/)

## 学校で報告するとき

1. **学校の担当者に確認する。** 教育機関の設置者による補償金の支払いと、教員等による利用情報の記録・報告を区別します。第35条に基づくコードの教材送信は検討対象となります。[公式手引き2～4頁](https://sartras.or.jp/wp-content/uploads/guide_to_filing_a_usage_report.pdf#page=2)
2. **その学校に必要な提出方法に従う。** サンプル調査の依頼を受けた学校は指定期間の利用をTSUMUGIで報告します。都度支払い方式の場合にも利用情報の提出が必要です。対象期間・締切は学校に届いた最新の案内で確認してください。[利用報告案内](https://sartras.or.jp/hokoku/)、[補償金規程第4条第3項](https://sartras.or.jp/wp-content/uploads/hosyokinkitei_20250821.pdf#page=7)
3. **実際に使った部分を特定する。** [作品情報と記録欄](work-identification.md) を使い、利用した版・ファイル・箇所と実際の送信を記録します。外部ライブラリ・引用・素材まで、Haruyuki Ishinakaの著作物としてまとめないでください。

サンプル校以外からの任意報告にも取扱規定があります。学校の担当者を通して、SARTRASに提出方法を確認してください。これは協力のお願いであり、ダウンロードした全員に報告義務を課すものではありません。[分配規程実施細則第2条](https://sartras.or.jp/wp-content/uploads/bunpaikiteisaisoku.pdf#page=1)

SARTRASへの正式な報告は学校の公式手続で行ってください。このリポジトリのIssueへの投稿は、正式な利用報告にはなりません。学生の氏名・名簿・アカウント情報などを公開Issueへ掲載する必要はありません。

## ゲームの公開・販売を相談するとき

相談相手は **Haruyuki Ishinaka（GitHub: [nyartry](https://github.com/nyartry)）** です。[プロジェクトのIssues](https://github.com/nyartry/EduGame3D/issues) が利用できる場合は、公開して差し支えない範囲で、次の内容を記載してください。機密情報を伴う場合は、最初に非公開で連絡する方法を確認してください。

```text

作品名・概要:

```

相談後、対象・配布方法・条件について許可を得てから公開してください。第三者素材の許諾は、その権利者の条件に従う必要があります。利用者自身の創作部分が本プロジェクトへ譲渡されることはありません。

## 制度と本プロジェクトの現在の状態

授業利用の報告や補償金の支払いは、学生作品の公開許可を兼ねません。逆に、個別の公開許可がSARTRASの分配対象を決めるわけでもありません。直接許諾した利用の制度上の扱いは、その条件と利用実態に応じて確認します。

EduGame3Dについて、SARTRASの登録・作品分類・分配対象への該当は未確認です。利用条件を掲載することだけで補償金は発生しません。素材・依存物の確認状況は [権利台帳](rights-inventory.md)、権利者側の準備と照会案は [準備調査](sartras-readiness-audit.md) に記録しています。
