## 使った版と箇所を残す方法

Gitで取得した作業フォルダでは、次のコマンドで版を調べられます。

```powershell
git rev-parse HEAD
git status --short
```

`git status --short` に変更が表示される場合、commit IDだけでは使用ファイルを再現できません。変更内容と、その授業で使った資料を学校の記録として保存してください。

GitHubのファイル画面では、特定commitを指す固定リンクを保存します。形式は `https://github.com/nyartry/EduGame3D/blob/<commit>/<file>#L<line>` です。山括弧の部分には実際の値を入れてください。更新で内容が変わるブランチURLだけに頼らず、ファイル名・行・文書の節も併記します。

履歴を含まない出力を使う場合、同梱の `CLEAN_SOURCE_EXPORT.json` の元commitと出力日時に加えて、実際に使用した配布物を保存します。未コミット変更を含む出力では、元commitだけで版を特定しないでください。
