## 使った版と箇所を残す方法

Gitで取得した作業フォルダでは、次のコマンドで版を調べられます。

```powershell
git rev-parse HEAD
git status --short
```

`git status --short` に変更が表示される場合、commit IDだけでは使用ファイルを再現できません。変更内容と、その授業で使った資料を学校の記録として保存してください。

GitHubのファイル画面では、特定commitを指す固定リンクを保存します。形式は `https://github.com/nyartry/EduGame3D/blob/<commit>/<file>#L<line>` です。山括弧の部分には実際の値を入れてください。更新で内容が変わるブランチURLだけに頼らず、ファイル名・行・文書の節も併記します。

履歴を含まない出力を使う場合、同梱の `CLEAN_SOURCE_EXPORT.json` の元commitと出力日時に加えて、実際に使用した配布物を保存します。未コミット変更を含む出力では、元commitだけで版を特定しないでください。

## 学校で保存する記録欄

以下はプロジェクト独自の準備用メモです。SARTRASへの提出項目・書式は、学校が使う公式の案内に合わせてください。[公式の利用報告案内](https://sartras.or.jp/hokoku/)

```text
作品名: EduGame3D
著作者・権利者表示: Haruyuki Ishinaka
配布元: https://github.com/nyartry/EduGame3D
使用版（タグ／commit／配布物の識別情報）:
使用したファイル・解説名・行又は節・分量:
出典の固定URL:
実際の公開・配布日（確認できる場合）:
第三者のコード・素材を含む場合の、その作品名と権利者:
授業名・実施日・対象学年等:
送信日時・方法・送信先の範囲・受信対象人数:
利用の根拠（第35条／引用等／個別許諾など）:
学校側の報告対象期間・担当者・提出状況:
```

実際に送信したものを記録し、利用していない部分や第三者の作品を本プロジェクトの権利者へ付け替えないでください。この記録を作るだけで、補償金の対象や報告の必要性が確定するものではありません。
